## Generated and runtime files (not in the repository)

| Path | Created by | Holds |
|------|------------|-------|
| `.env` | `./setup.sh` | Every setting and secret (mode 600). Never commit it |
| `.env.bak`, `.env.from-backup`, `.env.before-restore` | `./setup.sh`, `scripts/restore-volumes.sh` | Earlier copies of `.env` (mode 600) |
| `docker-compose.override.yml` | You | Local changes, for example ports published on `127.0.0.1` |
| `flowise_data/` | Flowise | Flowise's encryption key, session secrets and uploads |
| `n8n/shared/` | You, the MCP servers, `evals-run` | CPInfo files, files to scan, evals reports |
| `backups/` | `scripts/backup-volumes.sh` | Encrypted backup archives |
| `certs/*.pem` | You | Certificates of self-signed Check Point servers |

## Docker volumes

Docker Compose prefixes each name with the project name (`<project>_n8n_storage`).

| Volume | Service | Holds |
|--------|---------|-------|
| `postgres_storage` | `postgres` | The databases of n8n, Flowise and Langfuse |
| `n8n_storage` | `n8n`, `n8n-import` | n8n's own settings folder (`/home/node/.n8n`) and the import state |
| `langflow` | `langflow` | Langflow database, secret key and flows |
| `open-webui` | `open-webui` | Open WebUI users and chats |
| `qdrant_data` | `qdrant` | The RAG collection `cp_docs` |
| `ollama_storage` | `ollama-cpu`, `ollama-gpu` | Downloaded models |
| `aig_data`, `aig_db`, `aig_logs`, `aig_uploads` | `aig-webserver` | AI-Infra-Guard state and scan history |
| `policypilot_data` | `policypilot-mcp` | PolicyPilot sidecar database |

## Docker networks

| Network | Kind | Members |
|---------|------|---------|
| `lab` | Lab network, no published ports | Every lab service except `vuln-mcp`, `aig-webserver`, `aig-agent`, `aig-provision` and `aig-ui` (which has its own `aig-ui-access` network for its optional local port) |
| `dokploy-network` | External: the lab host's reverse-proxy network (`./setup.sh` creates it when missing) | `flowise`, `langflow`, `open-webui`, `langfuse`, `ollama-cpu`, `ollama-gpu` |
| `security-lab` | Internal: no internet, no route to the host | `vuln-mcp` and its clients (`n8n`, `n8n-import`, `flowise`, `langflow`, `builders-import`, `aig-agent`) |
| `ai-red-team` | Internal: no internet, no route to the host | `aig-webserver`, `aig-agent`, `aig-provision`, `aig-ui` (forwards the web UI only), and `litellm` to serve `lab-chat` |

## Keep this file current

When you add or move a folder, update this file and `.gitignore` (for runtime data), and add a
README to a new top-level folder.
